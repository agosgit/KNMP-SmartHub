## 4. 🔧 Perbaikan Seed Data

### Fix: Reporter per KNMP
**Sebelum:** Semua data produksi/distribusi/laporan menggunakan reporter yang sama (user pertama saja).
**Sesudah:** Setiap KNMP menggunakan reporter-nya masing-masing:

```
Produksi KNMP Muara Baru → Petugas TPI - Muara Baru
Produksi KNMP Brondong   → Petugas TPI - Brondong
Distribusi KNMP Belawan  → Koperasi - Belawan
Laporan KNMP Palabuhanratu → Penyuluh - Palabuhanratu
```

### Fix: Bobot AHP
- `w1 (Produksi)`: 0.351 → **0.352**
- `w2 (Distribusi)`: 0.232 → **0.233**
- Total bobot: 0.998 → **1.000** ✅
